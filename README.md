# VideoShelf

**VideoShelf** یک برنامه دسکتاپ ویندوز برای مدیریت، مرور، پیش‌نمایش، امتیازدهی و اشتراک‌گذاری مجموعه‌های بزرگ ویدئویی است.

> آخرین نسخه: **v3.9 — OpenSSH-first 443 Fallback + 10-Star Rating**

## قابلیت‌ها

- رابط کاربری مدرن و تیره با Python + PySide6
- مرور صدها ویدئو با Grid مجازی و Scroll روان
- جستجو و مرتب‌سازی بر اساس نام، حجم، مدت، تاریخ و امتیاز
- Preview هوشمند ویدئو بدون باز کردن Player
- Preview روی Hover و حالت Preview کارت‌های قابل مشاهده
- پردازش چندWorker و کنترل هوشمند مصرف CPU/RAM
- انتخاب چندتایی فیلم‌ها و حذف گروهی
- انتقال فایل‌ها به Recycle Bin یا حذف دائمی
- حفظ موقعیت Scroll بعد از حذف
- نمایش Poster، مدت، رزولوشن و حجم فایل
- امتیازدهی **۰ تا ۱۰ ستاره** با موس
- ذخیره امتیازها و Sort بر اساس Rating
- باز کردن فیلم با Player پیش‌فرض Windows
- Show in Explorer
- Web Library داخلی برای مشاهده فیلم‌ها در مرورگر
- Streaming با HTTP Range و قابلیت Seek
- Transcode لحظه‌ای FFmpeg برای فرمت‌هایی که مرورگر مستقیم پشتیبانی نمی‌کند
- Cloudflare Quick Tunnel
- تشخیص و لاگ کامل خطاهای Cloudflare Tunnel
- Fallback خودکار روی TCP 443 در شبکه‌هایی که Cloudflare Tunnel روی 7844 مسدود است
- استفاده از OpenSSH خود Windows برای Pinggy قبل از دانلود ابزار اضافه
- لینک عمومی دارای Token تصادفی
- کش دائمی Preview به‌صورت پیش‌فرض خاموش
- تمام Cacheهای اختیاری کنار خود برنامه نگهداری می‌شوند

## نحوه استفاده

1. جدیدترین ZIP را از پوشه **versions** دانلود کنید.
2. فایل ZIP را Extract کنید.
3. فایل **run.bat** را اجرا کنید.
4. در اولین اجرا، وابستگی‌های Python نصب می‌شوند.
5. وارد تب **مدیریت** شوید و فولدر اصلی ویدئوها را انتخاب کنید.
6. وارد تب **استفاده** شوید تا فیلم‌ها اسکن و نمایش داده شوند.

### انتخاب و حذف فیلم‌ها

- روی کارت‌ها کلیک کنید تا به Selection اضافه یا از آن حذف شوند.
- برای انتخاب بازه‌ای می‌توانید از Shift استفاده کنید.
- چند فیلم را می‌توان همزمان انتخاب و حذف کرد.
- گزینه Recycle Bin فایل‌ها را قابل بازیابی نگه می‌دارد.
- گزینه حذف دائمی قابل برگشت نیست.

### امتیازدهی

روی ستاره‌های هر کارت با موس کلیک کنید و از **۰ تا ۱۰** امتیاز بدهید.

از منوی Sort گزینه **امتیاز ★** را انتخاب کنید تا فیلم‌ها بر اساس Rating مرتب شوند.

### Preview

در مدیریت سه حالت Preview وجود دارد:

- **خاموش**
- **فقط Hover** — پیشنهادشده
- **همه کارت‌های روی صفحه**

حالت Hover برای هر ویدئو چند قسمت مختلف از فیلم را به‌صورت Preview کوتاه نمایش می‌دهد.

### اشتراک‌گذاری روی اینترنت

در بخش **اشتراک اینترنتی** دکمه شروع اشتراک Auto را بزنید.

VideoShelf به‌ترتیب:

1. Cloudflare Tunnel را بررسی می‌کند.
2. اگر مسیر Cloudflare روی پورت 7844 قابل استفاده باشد، Quick Tunnel می‌سازد.
3. اگر شبکه 7844 را مسدود کرده باشد، از OpenSSH خود Windows و Tunnel روی TCP 443 استفاده می‌کند.
4. در صورت نیاز، Pinggy CLI به‌عنوان آخرین fallback استفاده می‌شود.

لینک عمومی داخل برنامه نمایش داده می‌شود و با دکمه **کپی لینک** می‌توانید آن را کپی کنید.

### لاگ Tunnel

در بخش مدیریت، پنل Log برای بررسی موارد زیر وجود دارد:

- DNS
- اتصال TCP/UDP
- TLS/SNI
- cloudflared
- Pinggy/OpenSSH
- Health Check عمومی
- خطاهای Tunnel

با دکمه **کپی لاگ** می‌توانید کل Log را کپی کنید.

## سیستم پیشنهادی

- Windows 10 / 11
- Python 3.11+ / 3.13
- اینترنت فقط برای نصب اولیه وابستگی‌ها و قابلیت Tunnel
- FFmpeg توسط برنامه/وابستگی مربوطه مدیریت می‌شود
